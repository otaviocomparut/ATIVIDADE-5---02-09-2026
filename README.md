MODELO DESCENTRALIZADO
Esse modelo favorece a característica de Autonomia, pois permite que cada ponto da rota tome decisões rápidas e adaptadas às suas necessidades locais.
Em contrapartida, ele sacrifica a característica de Padronização, já que diferentes unidades podem adotar práticas distintas, reduzindo a uniformidade do processo.
